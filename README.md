## ⚡ About Me

- 💻 **Systems & Kernel Engineer:** Specializing in Linux kernel modules (LKM/DKMS), PCIe bus architecture, memory manipulation, and hardware-software coexistence.
- 🔬 **Reverse Engineering:** Disassembling, debugging, and analyzing closed binaries and drivers using **IDA Pro**, **x64dbg**, and **Ghidra**.
- 🏢 **Organizations:** Founder of **222corp** and subsidiary **Nexa**.
- 🎯 **Philosophy:** No bloated workarounds — write bare-metal, verifiable, high-performance code that fixes problems at the bus and register level.
